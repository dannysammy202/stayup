# Say More content upload

Upload the provided `saymore-content-100000-draft.zip` into this folder using GitHub's **Add file > Upload files** control. Keep this filename unchanged.

A new production build will read `data/saymore-content-100000-draft.zip` and publish the 100 approved starters plus 99,900 separately flagged editorial drafts as static data shards. Upload the original ZIP file, not the extracted Markdown folders.

The existing public feed stays restricted to approved entries. Use Settings > Preview unreviewed starters for editorial testing. See the root README for details.
